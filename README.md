# Alex Dev · Portfolio

A simple and complete web application built using **only HTML and CSS** — the Day 1–3 assignment project.

![GitHub Pages](https://img.shields.io/badge/deploy-GitHub%20Pages-blue)

## ✨ Features

- Semantic HTML5 structure (header, nav, main sections, footer)
- Modern CSS with **CSS Variables**, **Flexbox** and **Grid**
- Responsive design with **media queries** (mobile-first)
- Hover micro-interactions and smooth scrolling
- Inline SVG (no external images needed)
- Forms, lists, and links

## 🗂️ Concepts covered (per the 3-day plan)

| Day | Topic | Covered in this project |
|-----|-------|------------------------|
| Day 1 | HTML | Headings, paragraphs, links, images (SVG), lists, tables (implicit), forms, semantic elements |
| Day 2 | CSS | Selectors, colours, fonts, box model, margin/padding, **Flexbox**, **Grid**, hover effects, responsive design |
| Day 3 | Assignment | Complete app + Git version control + GitHub Pages |

## 🚀 Run locally

Just open `index.html` in your browser:

```bash
open index.html
```

Or serve it with a simple local server (optional):

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## 📦 Git & GitHub workflow

```bash
# 0. Add the remote (replace with your repo URL)
git remote add origin https://github.com/YOUR_USERNAME/html-css-task.git

# 1. Push
git push -u origin main

# 2. Publish on GitHub Pages
#   - GitHub repo → Settings → Pages
#   - Source: "Deploy from a branch", main branch, root folder → Save
#   - Your site goes live at:
#     https://YOUR_USERNAME.github.io/html-css-task
```
